The Panel Reviewer role is the Basic pre-review. Use the same prompt
in the same chat session. After it returns its critique, leave the
chat open and continue to step 2.

`=== PROMPT END ===` markers in [`../basic/prompt.md`](../basic/prompt.md).

stage. Read the output.
